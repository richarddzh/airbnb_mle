# Tiny-LLM 分析报告合集 / Tiny-LLM Analysis Reports

面向初学者的详细中文解读，HTML 格式（左侧目录 + 右侧正文，浅色主题，含 Mermaid 图示）。

## 内容 / Contents

| 文件 | 主题 |
| --- | --- |
| `index.html` | 合集首页与导航，三者关系图 |
| `esp32-ai.html` | [slvDev/esp32-ai](https://github.com/slvDev/esp32-ai) 深度解读：代码构成、训练、运行、纯 C 推理、Transformer/PLE 架构、三级存储内存优化 |
| `tinystories-paper.html` | 论文 [arXiv:2305.07759](https://arxiv.org/abs/2305.07759) TinyStories 中文分析 |
| `llama2c.html` | [karpathy/llama2.c](https://github.com/karpathy/llama2.c) 中文分析 |
| `gemma-ple.html` | Per-Layer Embeddings (PLE) 专题：Google Gemma 3n 内存技术溯源、原理与代码级实现，及其在 esp32-ai 中的复刻 |
| `assets/style.css` | 共享样式（浅色主题、固定侧栏目录） |
| `assets/common.js` | 自动生成目录、滚动高亮、初始化 Mermaid |

## 使用 / Usage

直接用浏览器打开任一 `.html` 文件即可。Mermaid 图示通过 CDN 加载，需联网渲染。

> 目录 / 文件名使用英文，正文内容为中文。
